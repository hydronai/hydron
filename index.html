Hydron is a local-first AI workspace that brings your models, your coding agents, and your code together on your own machine.

01 / 04

Hydron app

Your home base for local AI. Chat with a model running on your PC or with a connected coding agent, and keep related conversations together in Projects.

02 / 04

Launch

See every supported agent on your PC — Codex, Claude Code, Copilot CLI and more — alongside Hydron's own local model engine, and install models from a built-in command console.

03 / 04

Hydron CLI

Type hydron in any shell for a coding agent on a local model. It starts read-only, attaches files with @, runs commands with !, and /undo reverts any edit.

04 / 04

Hydron IDE

Open a folder and edit beside your agents. Switch to VS Code when you need your extensions, press Ctrl+I to ask an agent about a file, and run it with F5.
