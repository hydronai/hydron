Install

From download to first prompt.

Hydron ships as a self-contained Windows installer. You do not need to install .NET or another local model application first.

Download Hydron SetupSystem requirements

System requirements

Operating systemWindows 10 or Windows 11, x64.
Memory8 GB minimum. 16 GB or more recommended for useful local models.
StorageAt least 2 GB for Hydron, plus space for each model you download.
GraphicsA compatible GPU improves speed; CPU-only use is supported.
InternetNeeded for the installer, model downloads, external agents, and optional research.
.NETIncluded. No separate runtime installation is required.

Install in four steps

Download the installer

Use the official Hydron release link on this page.

Open Hydron Setup

Windows may show a reputation warning while the alpha installer is unsigned. Continue only if you downloaded it from the official repository.

Choose shortcuts

The installer adds Hydron to your Start menu, can create a desktop shortcut, and adds the hydron command to your user PATH.

Launch Hydron

The app, CLI, .NET runtime, and local inference engine are installed together.

First run

Set up your workspace

1. Pick a folder

Choose the project folder coding agents may inspect. File changes stay disabled until you explicitly allow write access.

2. Install a small model

Open Launch, choose Available Models, and start with a compact model that fits your memory.

3. Connect agents

Install and sign in to Codex, Claude Code, or another supported agent separately. Hydron detects them automatically.

4. Start working

Chat with a model, open your folder in the IDE, or launch an agent for a project task.

Quick start

Common workflows

Chat with a model

Select a downloaded model, create a new chat, type your prompt, and press Enter. Shift+Enter adds a new line.

Launch an agent

Open Launch, choose an installed agent, select a workspace when asked, and use that provider's authenticated session.

Use the IDE

Open IDE, choose a folder, select a file, edit it, then use Run or Build when the required toolchain is installed.

Use the CLI

Try hydron list, hydron pull qwen3:0.6b, or hydron run qwen3:0.6b in a new terminal window.

FAQ

Troubleshooting

Why does Windows warn me about the installer?

The current alpha is not yet signed with a trusted Windows certificate. Download only from the official Hydron repository and verify the release checksum when provided.

Why is a model slow or unable to load?

The model may be too large for the available memory, or your CPU/GPU may not support it efficiently. Close memory-heavy apps and try a smaller model.

Why is an agent marked Not installed?

Hydron does not bundle third-party agents. Install the agent's official CLI, sign in, restart Hydron, and press Refresh.

Why will my project not run?

Hydron calls the language tools installed on your PC. Install the required compiler or interpreter, then reopen Hydron.

Can I use Hydron offline?

Downloaded local models can run offline. New downloads, cloud agents, and optional web research require internet access.

Start on your own machine.

The Windows installer includes the Hydron desktop app, CLI, .NET runtime, and local model engine.
