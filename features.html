Capabilities

The essentials of a local AI workflow, designed to work together.

Run models on your PC

Download and use supported models locally. No cloud subscription is needed for local conversations.

Open your own folder

Choose a project folder, search its files, edit code, and see live output beside your work.

Your coding agents

62 skills

Chats that stay saved

Model Shop

Any model from Hugging Face, one click away.

Search Hugging Face straight from Hydron, or open an Ollama name, an hf:owner/repo reference or a direct .gguf link. Not sure where to start? Hydron's verified picks cover everything from tiny to capable.

  • Install any GGUF model from Hugging Face, the Ollama library or a link
  • Downloads are checked against the SHA-256 the source publishes
  • Browse the most-downloaded GGUF models on Hugging Face
  • Verified picks such as Qwen, Llama, Gemma, Phi, Mistral and DeepSeek
Skills

Teach the model how you like to work.

Skills change how the model writes, thinks and codes. There are 62 to choose from today, with more to come — from Concise and Plain English to Copy editor, Tutor and Reviewer.

  • Install only the skills you want
  • Switch each installed skill on or off
  • Applies to the main chat, the side chat and the CLI
  • Search and filter by category
Integrated IDE

Edit code and see the result.

Open the folder you choose and work beside the AI tools using it. Hydron calls the language toolchains already installed on your PC.

  • Switch between the Hydron editor and VS Code
  • Ctrl+I opens Ask Hydron: Ion explains code, finds bugs and adds tests
  • You stay in control of every edit
  • Command palette, file explorer, and workspace search
  • Built-in terminal, problems, and output panels
  • Run with F5, plus Build and auto-save
Agent ecosystem

Bring the agents you already trust.

Hydron detects supported coding agents installed on your PC, including Codex, Claude Code, Hermes, OpenClaw, OpenCode, and Copilot CLI.

  • Use your own subscriptions or API access
  • Each provider keeps its own terms and privacy rules
  • Workspace and write access stay explicit
Terminal agent

A coding agent in your terminal.

Type hydron in any shell and tell it what to work on. It runs on a local model or an agent such as OpenCode, and asks for a change the way you'd ask a teammate.

  • Shift+Tab switches mode; Ctrl+L clears
  • @ attaches a file (Tab completes the path), ! runs a shell command
  • Type / to see every command

Size matters

Larger models need more memory, storage, and processing power.

Speed varies

Your CPU, GPU, available memory, and model size all affect response speed.

Start small

If you are unsure, begin with a compact model and move up gradually.

Very large models such as GLM 5.2 can require server-grade hardware and hundreds of gigabytes of storage. They may be extremely slow or fail to load on a typical PC and are not recommended for everyday desktop use.
