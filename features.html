Features

Everything you need to build with local AI.

Hydron brings local model chat, supported coding agents, model management, and project tools into one Windows application.

Download for WindowsGet started

Chat with a local model or a connected coding agent.

Capabilities

The essentials of a local AI workflow, designed to work together.

Run models on your PC

Download and use supported models locally. No cloud subscription is needed for local conversations.

Open your own folder

Choose a project folder, search its files, edit code, and see live output beside your work.

Helpful code editing

Syntax highlighting, automatic indentation, suggestions, and file search for common languages.

Your coding agents

Hydron finds supported agents installed on your PC and gives you one place to open and use them.

Simple commands

Install, run, list, and remove models from the Hydron app or your terminal.

Chats that stay saved

Conversations stay on your computer and remember which model or agent you selected.

Integrated IDE

Edit code and see the result.

Open the folder you choose and work beside the AI tools using it. Hydron calls the language toolchains already installed on your PC.

  • Code editor and file explorer
  • Run and Build controls
  • Syntax highlighting and indentation
  • File search and resizable runtime output
Agent ecosystem

Bring the agents you already trust.

Hydron detects supported coding agents installed on your PC, including Codex, Claude Code, Hermes, OpenClaw, OpenCode, and Copilot CLI.

  • Use your own subscriptions or API access
  • Each provider keeps its own terms and privacy rules
  • Workspace and write access stay explicit
Terminal agent

A coding agent in your terminal.

Type hydron to start Ion, Hydron's command-line agent, running on a local model. Ask for a change and it reads, edits, and runs tests, then shows you what changed.

  • Starts read-only; press Shift+Tab to change mode
  • /undo reverts, Esc interrupts
  • /init creates a HYDRON.md memory file for your project

Size matters

Larger models need more memory, storage, and processing power.

Speed varies

Your CPU, GPU, available memory, and model size all affect response speed.

Start small

If you are unsure, begin with a compact model and move up gradually.

Very large models such as GLM 5.2 can require server-grade hardware and hundreds of gigabytes of storage. They may be extremely slow or fail to load on a typical PC and are not recommended for everyday desktop use.

Privacy architecture

No account. No Hydron cloud.

What stays local

  • Local model inference
  • Chats and attachments
  • Settings, workspace paths, and downloaded models

What you choose to connect

  • Third-party coding agents, under their own terms
  • Optional web research, off by default
  • Model downloads from their public sources
